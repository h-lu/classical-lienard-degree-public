# From a numerical assertion to its proof

The main article and electronic supplement each build from their transitive TeX inputs. The [standalone certificate archive](source/certificates.tar.gz) contains the programs, exact inputs, English fixed-field proof, required table sources and four reference transcripts. In an extracted archive run `./replay-all.sh` from `certificates/`. In the editable bundle use `./source/replay-all.sh`. All input literals used for acceptance are dyadic integers or rational numbers. Some trajectory and interval proposals were obtained numerically. The checks accept them using residual and enclosure inequalities.

In the standard-library integrator the order-36 dyadic proposal is evaluated against the whole polynomial residual of degree at most 216. A one-sided Lipschitz bound transports the defect tube, and a transverse event bracket transports it to an interval of section ordinates. For a fixed field, hyperbolicity also needs the derivative or divergence bound across an interval containing the zero. The fixed-field program performs this extra check.

The standalone and editable archives both include an [exact check of the action coordinates and orientation](source/verification/check_action_coordinates.py). Using the even part of each fixed input, it compares polynomial primitives in \(z\) and \(u=z^2/2\) coefficient by coefficient. Two endpoint tests distinguish the mixed-coordinate expression, and a moving-endpoint example checks the sign and the factor two in the oriented integral. Its four output lines are in the [coordinate check output](source/verification/action-coordinates.txt). The analytic use of the actions is in Proposition 3.3 and in Sections S3 and S5 of the supplement.
